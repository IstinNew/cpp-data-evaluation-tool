# C++ Data Evaluation Tool - Instructions

## Getting Started
- Read data from a CSV file
- Calculate mean, median, and mode of the data
- Output the results in a user-friendly format
- main.cpp: The main C++ code file.

### Offline Usage

#### Option 1: Using Command Line
1. **Clone the Repository**:
    ```sh
    git clone https://github.com/IstinNew/cpp-data-evaluation-tool.git
    cd cpp-data-evaluation-tool
    ```

2. **Ensure C++ is Installed**:
    - Make sure you have a C++ compiler installed on your system (e.g., GCC for Linux, VS Code for Windows, Xcode for macOS).

3. **Compile the Program**:
    - Compile the C++ source code:
    ```sh
    g++ -o data_evaluation_tool main.cpp
    ```

4. **Run the Program**:
    - Execute the compiled program:
    ```sh
    ./data_evaluation_tool
    ```

#### Option 2: Using Visual Studio Code
1. **Clone the Repository**:
    ```sh
    git clone https://github.com/IstinNew/cpp-data-evaluation-tool.git
    cd cpp-data-evaluation-tool
    ```

2. **Open VS Code**:
    - Open Visual Studio Code.
    - Open the project folder by selecting `File` > `Open Folder` and navigating to the cloned repository.

3. **Install C++ Extensions**:
    - Install the necessary extensions for C++ development. Go to the Extensions view by clicking on the Extensions icon in the Activity Bar on the side of the window or by pressing `Ctrl` + `Shift` + `X`.
    - Search for and install the `C/C++` extension by Microsoft.

4. **Configure Build Task**:
    - Go to `Terminal` > `Configure Default Build Task...` and select the appropriate compiler.

5. **Build the Program**:
    - Press `Ctrl` + `Shift` + `B` to build the program using the configured task.

6. **Run the Program**:
    - Use the integrated terminal to run the compiled program:
    ```sh
    ./data_evaluation_tool
    ```

### Online Usage (Google Colab)
1. **Open in Google Colab**:
    - Go to [Google Colab](https://colab.research.google.com/).
    - Click on `File` > `Upload Notebook`.
    - Upload the `data_evaluation_tool.ipynb` file from the repository.

2. **Run the Notebook**:
    - Follow the instructions in the notebook cells.
    - Run the code cells sequentially to perform data evaluation and generate reports.
